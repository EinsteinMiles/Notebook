# 一、文件和文件夹

## 1.文件操作

### （1）文件打开

```python
file = open('filename','mode')
```

- 访问模式

  ```python
  #r:只读：如果文件不存在，报错。不支持写
  #w：写入：如果文件不存在，新建文件。写入时覆盖原文件内容
  #a：追加：如果文件不存在，新建文件。写入时在原文件内容基础上追加新内容
  #b:二进制
  #+：可读可写
  ```

### （2）读写操作

```python
file = file.write('context')
#num:表示要从文件中读取数据的长度(单位：字节)，省略表示读取所有数据
file = fiel.read(num)
#将整个文件内容一次性读取，返回一个列表，每一行为一个元素，除最后一行外，每个元素末尾带换行符\n
file = file.readlines()
#一次性读取一行内容，第一次调用读取一行，第二次调用读取两行，不带换行符\n
file = file.readline()
```

### （3）关闭

```python
file = file.close()
```

### （4）移动指针

```python
#起始位置：0开头，1当前位置，2文件结尾
#offset：假设其实位置是开头，offset是5，文件指针就指在第6个字节上
file.seek(offset,positon)
```

### （5）文件备份

```python
#输入目标文件名
filename = input('backup_filename')
#规划备份文件的名字
#rfind:从右侧开始查找子字符串最后一次出现的位置
dot_position = filename.rfind('.')
#组织新名字
if dot_position > 0:
  suffix = filename[dot_position:]
else:
  print("error")
  
 new_name = filename[:dot_position] + 'backup' + suffix
```

## 2.文件夹操作

### （1）OS模块

```python
import os
#使用os模块相关功能
os.function_name()
```

### （2）文件及文件夹重命名

```python
#目标文件名可以写路径，否则默认在当前文件夹下面
os.rename('old_filename','new_filename')
os.rename('old_flodername','new_flodername')
```

### （3）删除文件

```python
#只能删除文件，不能删除文件夹
os.remove(filename)
```

### （4）创建/删除文件夹

```python
os.mkdir(flodername)
rmdir(flodername)
```

### （5）获取当前文件所在目录路径

```python
os.getcwd()
print(os.gtcwd())
```

### （6）改变默认目录

```python
#在conten目录下，创建一个目录content2
#就是将content2这个文件夹的默认目录改成content
os.chdir(content) #绝对路径
os.mkdir(content2)
```

### （7）获取某个文件夹下所有文件和文件夹的名字，返回列表

```python
os.listdir(content)
```

### （8）路径自动连接

```python
file_path = os.path.join(文件层级)
```

### （9）显示文件夹中所有元素

```python
#返回True或者False
os.path.isdir(element)
```

### （10）遍历目录

```python
os.scandir(file,attribute)
```
