# 一、HTML

## 1.HTML4

#### 1. HTML基本结构

1. ```html
   <html>
       <head>
           
       </head>
       
       <body>
      
       </body>
   </html>
   ```

2. 注释

   ```html
   <!-- 这是一个注释-->
   <!-- 快捷键同pycharm-->
   ```

3. 文档声明:告诉浏览器当前网页版本

   ```html
   <!DOCTYPE html> <!--文档声明,此为h5-->
   ```

4. 字符编码ascii码->UTF-8(万国码)

5. 语言设置

   ```html
   <html lang = "zh-CN"
   ```

6. 标准结构

   ```html
   <!DOCTYPE html>
   <html lang="zh-CN">
       <head>
           <meta charset="UTF-8">
           <title>我是一个标题</title>
       </head>
       <body>
           我是网页内容
       </body>
   </html>
   ```

#### 2.标签

1. 排版标签

   ```html
   <!DOCTYPE html>
   <html lang="zh-CN">
   <head>
       <meta charset="UTF-8">
       <title>排版标签</title>
   </head>
   <body>
       <h1>我是一级标题</h1> <!--h1是最重要的标签,标题标签-->
       <p>这是段落内容</p> <!--段落标签;p中不能再有标题且不能有div-->
       <div></div> <!-- 没有实际含义，一般用来包裹一段内容-->
       <h2>我是二级标题</h2>
       <h3>我是三级标题</h3>
       <h4>我是四级标题</h4>
       <h5>我是五级标题</h5>
       <h6>我是六级标题</h6>
       
   </body>
   </html>
   ```

2. 语义化标签

   - 标签呈现的默认效果不重要，语义最重要
   - 作用
     - 代码的可读性强
     - 有利于seo(搜索引擎)优化
     - 方便设备解析(屏幕、盲人阅读器等)

3. 块内与行内代码

   - 独占一行的称为块级元素，不独占一行的称为行内元素
   - 块级元素
     - 块级元素中能写行内元素，也能写块级元素
     - 行内元素中能写行内元素，但不能写块级元素
     - p标签中不能写块元素

4. 文本标签

   ```html
   !DOCTYPE html>
   <html lang="zh-CN">
   <head>
       <meta charset="UTF-8">
       <title>文本标签</title>
       <!--文本标签作用:
           1.用于包裹词汇短语等
           2.常写在排版标签里
           3.文本标签通常都是些行内元素
       -->
   </head>
   <body>
       <!--常用-->
       <!--em：需要着重阅读的内容-->
       <!--strong:十分重要的内容-->
       <!--span:没有语义，用于包裹短语的通用容器-->
       <P>
           <strong>预防电信诈骗</strong>,<span>请安装</span>:<em>国家反诈中心APP</em>
       </P>
   
       <!--不常用-->
       <!-- 
           cite:作品标题;
   		dfn:专属术语;
   		del与ins:删除与插入文本
           sub与sup:下标文字与上标文字;
   		code:一段代码;
   		abbr:缩写
           addr:地址信息(块级元素)
       -->
       
   </body>
   </html>
   ```

5. 图片标签

   - alt:配置图片的描述:当图片展示不出来就显示alt的内容
   - 高度和宽度调一个就行，不然会比例失调
   - 相对路径 
     - ./ 当前级
     - ../ 上一级
     - / 下一级
   - 绝对路径
     - 本地绝对路径(用的少)
     - 网络绝对路径 直接写(常用)

   ```html
   <!DOCTYPE html>
   <html lang="zh-CN">
   <head>
       <meta charset="UTF-8">
       <title>图片标签</title>
   </head>
   <body>
       <img width="400px" src="./米娘.jpg" alt="只狼"> <!--行内元素--> 
   </body>
   </html>
   ```

6. 补充常用标签

   ```html
   <!DOCTYPE html>
   <html lang="zh-CN">
   <head>
       <meta charset="UTF-8">
       <title>补充常用标签</title>
   </head>
   <body>
       <!-- 换行标签br -->
       <a href="https://www.baidu.com">去百度</a><br>
       <a href="https://www.jd.com">去京东</a>
   
       <!-- 分割线 -->
       <div>第一段</div>
       <P>这是一段测试文字</P>
       <hr>
       <div>第二段</div>
       <p>这是另一段测试文字</p>
   
       <!-- 按原文显示 -->
       <pre>
           i    love    you
             i  love  you
                love
       </pre>
   </body>
   </html>
   ```

   

#### 3.超链接

1. 跳转页面

   ```html
   <!DOCTYPE html>
   <html lang="zh-CN">
   <head>
       <meta charset="UTF-8">
       <title>跳转页面</title>
   </head>
   <body>
       <!-- 
           target:_blank:在新的页面中打开；_self:在当前页面打开
           href：目标网页
           a标签虽然是一个行内元素，但是可以包裹除了自身外的任意标签
        -->
       <a target="_blank" href="https://pro.jd.com/mall/active/2vx2zyXR2KhRouYS6LrSEdnLF1P5/index.html">京东家电</a>
       <a target="_self" href="https://www.baidu.com">百度</a>
   </body>
   </html>
   ```

2. 跳转文件

   ```html
   <!DOCTYPE html>
   <html lang="zh-CN">
   <head>
       <meta charset="UTF-8">
       <title>跳转文件</title>
   </head>
   <body>
       <a target="_blank" href="./米娘.jpg">米娘</a>
       <!-- 
           浏览器可以打开，但是要强制下载
           download的值可以指定为下载时文件的名字
       -->
       <a target="_blank" href="./米娘.jpg" download>下载米娘</a>
   </body>
   </html>
   ```

3. 跳转锚点

   ```html
   <!DOCTYPE html>
   <html lang="zh-CN">
   <head>
       <meta charset="UTF-8">
       <title>跳转锚点</title>
   </head>
   <body>
       <a href="#woman">看米娘</a> <!--跳转到锚点-->
       <a href="#大厅">看大厅</a>
   
       <a name="woman"></a> <!--添加一个锚点-->
       <p>我是米娘</p>
       <img src="./米娘.jpg">
   
       <p id="大厅">我是大厅</p> <!--用id添加一个锚点,id是一个通用属性，最好不用数字开头;推荐使用此方法加锚点-->
       <img width="800px" src="./7.jpg">
   
       <a href="javascript:alert(1);">点我弹窗</a> <!--插入javascript脚本-->
   
       <p>页面已到底</p>
       <a href="#">回到顶部</a> <!--不写#号就是刷新页面-->
   </body>
   </html>
   ```

4. 唤起指定应用

   ```html
   <!DOCTYPE html>
   <html lang="zh-CN">
   <head>
       <meta charset="UTF-8">
       <title>唤起指定应用</title>
   </head>
   <body>
       <a href="tel:10086">电话联系</a>
   </body>
   </html>
   ```

#### 4.列表

1. 有序列表 ordered list

   - li:list items
   - 无论是ul还是ol,他的子元素最好是li
   - li最好不要单独使用
   - 列表可以嵌套
   - 自定义列表一个术语名称可以有多个术语描述

   ```html
   <!DOCTYPE html>
   <html lang="zh-CN">
   <head>
       <meta charset="UTF-8">
       <meta name="viewport" content="width=device-width, initial-scale=1.0">
       <title>有序列表</title>
   </head>
   <body>
       <h2>
           要把大象放冰箱要几步?
       </h2>
       <ol>
           <li>打开冰箱门</li>
           <li>把大象放进冰箱</li>
           <li>关闭冰箱门</li>
       </ol>
   </body>
   </html>
   ```

#### 6.表单

1. 基本结构

   - 表单是网页中的一个交互区域，用于收集用户提交的数据

   ```html
   <!DOCTYPE html>
   <html lang="zh-CN">
   <head>
       <meta charset="UTF-8">
       <title>表单基本结构</title>
   </head>
   <body>
       <form action="https:www.bing.com/s" method="get"> <!--/s：呈现的是搜索结果,取决于具体网页-->
           <input type="text" name="wd"> <!--wd也必须写，取决于具体网页-->
           <button>搜索</button>
       </form>
       <hr>
       <form action="https://search.jd.com/search" target="_blank">
           <input type="text" name = "keyword">
           <button>买东西</button>
       </form>
   </body>
   </html>
   ```

2. 表单控件

   ```html
   <!DOCTYPE html>
   <html lang="zh-CN">
   
   <head>
       <meta charset="UTF-8">
       <title>表单控件</title>
   </head>
   
   <body>
       <!-- 表单是网页中的一个交互区域，用于收集用户提交的数据 -->
       <form action="https://search.jd.com/search">
           <div>
               <!-- 文本输入框 -->
               <label for="zhanghu">账户: </label> <!--获得焦点,用for和id将两个标签联系起来-->
               <input id="zhanghu" type="text" name="account" value="张三" maxlength="10"> <!--value提供默认值-->
               <br>
               <!-- 密码输入框 -->
               <label> <!--常用此种联系方式-->
                   密码:
                   <input id="mima" disabled type="password" name="pwd"> <!--disabled禁用表单控件-->
               </label>
   
               <br>
               <!-- 单选框 -->
               性别：
               <input type="radio" name="gender" value="male" checked>男 <!--checked默认勾选-->
               <input type="radio" name="gender" value="female">女 <!--name分组用,必写;value也必写-->
               <br>
               <!-- 复选框 -->
               爱好:
               <input type="checkbox" name="hobby" value="somke">抽烟 <!--复选框checkbox-->
               <input type="checkbox" name="hobby" value="drink">喝酒
               <input type="checkbox" name="hobby" value="perm">烫头
               <!-- 文本域 -->
               <br>
               其他:
               <textarea name="other" cols="25" rows="5"></textarea>
               <!-- 下拉框 -->
               <br>
               籍贯:
               <select name="place">
                   <option value="皖" selected>安徽省</option> <!--selected添加默认-->
                   <option value="浙">浙江省</option>
               </select>
               <!-- 隐藏域 -->
               <input type="hidden"> <!--可以携带name和value防止非法注册-->
               <br>
               <!-- 提交/重置按钮 -->
               <input type="submit" value="确认">
               <input type="reset">
               <!-- 普通按钮 -->
               <button type="button">检测账户是否被注册</button>
               <!-- 分类 -->
               <fieldset>
                   <legend>分类</legend>
                   <div>这里是分类的内容</div>
               </fieldset>
           </div>
   
       </form>
       </form>
   </body>
   
   </html>
   ```

#### 10.meta元数据

```html

<html lang="zh-CN">
<head>
    <!-- 配置字符编码 -->
    <meta charset="UTF-8">

    <!-- 针对IE的兼容性设置 -->
    <meta http-equiv="X-UA-Compatible" content="IE=edge">

    <!-- 针对移动端设备的一个配置 -->
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    
    <!-- 配置网页关键字 -->
    <meta name="Keywords" content="测试">

    <!-- 配置网页自动刷新 -->
    <!-- 10s后刷新去百度 -->
    <meta http-equiv="refresh" content="10;url=https://www.baidu.com">

    <title>Meta</title>
</head>
<body>
    <h1>hello world</h1>
</body>
</html>
```

# 二、CSS

## 1.CSS2

#### 1.样式

1. 行内样式

   - 在标签中通过行内属性添加样式
   - 不推荐使用

   ```html
   <!DOCTYPE html>
   <html lang="zh-CN">
   <head>
       <meta charset="UTF-8">
       <meta name="viewport" content="width=device-width, initial-scale=1.0">
       <title>CSS编写位置-行内样式</title>
   </head>
   <body>
       <h1 style="color: red;">hello world</h1>
   </body>
   </html>
   ```

2. 内部样式

   - style中的代码是css,而非html
   - 理论上也可以写在body里面,但是通常写在head中

   ```html
   <!DOCTYPE html>
   <html lang="zh-CN">
   <head>
       <meta charset="UTF-8">
       <meta name="viewport" content="width=device-width, initial-scale=1.0">
       <title>内部样式</title>
       <style>
           h1{
               color: green;
               font-size: 50px;
           }
       </style>
   </head>
   <body>
       <h1>hello world</h1>
   </body>
   </html>
   ```

3. 外部样式

   - rel:所链接的资源与当前文档的关系
   - 最常用
   - 优先级:行内样式>内部样式=外部样式

   ```html
   <!DOCTYPE html>
   <html lang="zh-CN">
   <head>
       <meta charset="UTF-8">
       <meta name="viewport" content="width=device-width, initial-scale=1.0">
       <title>外部样式</title>
       
       <!-- 引入链接 -->
       <link rel="stylesheet" href="./03_css_外部样式.css">
   </head>
   <body>
       <p>hello world</p>
   </body>
   </html>
   ```

#### 2.代码规范

```html
<!DOCTYPE html>

#### 4.复合选择器

1. 交集选择器

   ```html
   <!DOCTYPE html>
   <html lang="zh-CN">
   <head>
       <meta charset="UTF-8">
       <meta name="viewport" content="width=device-width, initial-scale=1.0">
       <title>交集选择器</title>
       <style>
           .rich {
               color: goldenrod;
           }
           .beauty {
               color: palevioletred;
           }
   
           /* 交集选择器：元素选择器.类选择器 用的很多 */
           p.beauty {
               color: turquoise;
           }
           /* .rich.beauty 可以用两个类型组成交集 很少使用*/
       </style>
   </head>
   <body>
       <h2 class="rich">土豪张三</h2>
       <h2 class="beauty">明星李四</h2>
       <hr>
       <p class="beauty">小狗旺财</p>
       <p class="beauty">小猪佩奇</p>
   </body>
   </html>
   ```

2. 并集选择器

   ```html
   <!DOCTYPE html>
   <html lang="zh-CN">
   <head>
       <meta charset="UTF-8">
       <meta name="viewport" content="width=device-width, initial-scale=1.0">
       <title>并集选择器</title>
       <style>
           .rich {

               color: palevioletred;
           }
           .dog {
               color: turquoise;
           }
           .pig {
               color: darkorange;
           }
           /* 并集选择器，用逗号连接基本选择器 */
           .rich,
           .beauty,
           .dog,
           .pig {
               font-size: 34px;
               background-color: bisque;
               width: 160px;
           }
       </style>
   </head>
   <body>
       <h2 class="rich">土豪张三</h2>
       <h2 class="beauty">明星李四</h2>
       <hr>
       <p class="dog">小狗旺财</p>
       <p class="pig">小猪佩奇</p>
   </body>
   </html>
   ```

3. HTML间的元素关系

   - 父元素：**直接**包裹某个元素的我元素，就是该元素的父元素
   - 子元素：被父元素直接包裹的元素
   - 祖先元素和后代元素
   - 兄弟元素

4. 后代选择器

   - 由基本选择器和前面的复合选择器组成，中间用空格隔开

5. 子代选择器

   - 用大于号连接

6. 兄弟选择器

   - 用加号连接
   - 仅仅相邻的且在其后面的才会被修改
   - 用波浪线连接可以修改在其后所有的兄弟标签，不包括自己

7. 属性选择器

   - 用[]将属性包裹起来
   - 属性可以带值
     - =
     - ^= 以开头
     - $=以结尾
     - *= 只要有某个字符就行
